# NariSurakshaAI

NariSurakshaAI is an AI-powered women safety platform designed to provide immediate assistance during emergencies. The application combines Machine Learning, real-time location services, and emergency communication tools to enhance personal safety and security.

## Overview

Women's safety remains a major concern in many regions. NariSurakshaAI aims to address this challenge by offering smart safety features such as threat detection, emergency alerts, live location sharing, and fake call assistance.

The platform is built with a user-friendly interface and leverages Artificial Intelligence to provide quick and effective support during critical situations.

## Features

### AI-Based Threat Detection

* Predicts potential threats using Machine Learning models.
* Analyzes user inputs and safety-related data.

### Live Location Tracking

* Captures the user's current location.
* Generates Google Maps links for quick sharing.

### Emergency WhatsApp Alert

* Sends emergency messages to predefined contacts.
* Includes the user's live location for immediate assistance.

### Fake Call Assistance

* Simulates an incoming call to help users exit uncomfortable or unsafe situations.

### Emergency Incident Records

* Stores safety incidents for future reference and analysis.

### User-Friendly Interface

* Clean and responsive interface built with Streamlit.
* Easy navigation and quick access to safety features.



